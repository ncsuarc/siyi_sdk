# @siyi-sdk/remote

TypeScript client for the SIYI SDK camera service: the browser counterpart of the Python
`RemoteCamera`, with React bindings. It talks JSON-RPC to the service on the aircraft
directly, with no backend in between.

```ts
import { RemoteCamera } from "@siyi-sdk/remote";

const cam = new RemoteCamera("ws://192.168.144.30:8765", { name: "shimmer" });
await cam.connect();
await cam.call("set_attitude", { yaw_deg: 0, pitch_deg: -90 });
```

See [docs/remote.md](../../docs/remote.md#browser-and-typescript) for usage.

- `src/generated.ts` is generated by `python scripts/generate_ts_types.py`. Don't edit it by hand.
- `npm test` starts the real camera service on the fake camera from `tests/remote`.
  It runs `uv run python` by default; set `SIYI_PYTHON` to use another interpreter.
